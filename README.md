# HR Attrition Analysis Dashboard

## Overview
This project analyzes HR employee data to identify attrition patterns and workforce trends. The objective was to help stakeholders understand why employees leave, which groups are most at risk, and how data-driven insights can support retention strategies.

## Dataset
- HR employee dataset containing demographic, role, and attrition-related attributes
- Records include department, age group, job role, and attrition status

## Analysis Performed
- Data cleaning and preprocessing using Python
- Attrition rate analysis across departments and age groups
- Identification of high-risk employee segments
- KPI creation for workforce monitoring

## Key Insights
- Certain departments showed significantly higher attrition rates
- Attrition was more prominent in specific age and role categories
- Workforce trends highlighted areas requiring targeted retention efforts

## Dashboard
- Interactive dashboard built to track attrition, workforce distribution, and trends
- Designed for non-technical stakeholders to quickly interpret insights

## Tools Used
- Python (data cleaning & preprocessing)
- Power BI / Tableau (dashboard & visualization)

## Outcome
The dashboard provides a decision-ready view of employee attrition, enabling HR teams to:
- Monitor workforce stability
- Identify risk-prone segments
- Support data-driven retention initiatives
